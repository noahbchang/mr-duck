<h1>Mr. Duck: Desktop Assistant</h1>
A fun desktop assistant with a set of utilites, handy when used in tandem with fullscreen applications.

<h2>Setup</h2>
For now, download the repo right here and run the main.py file. Requires PySide6. I plan on packaging it into an executable eventually.

<h2>Usage</h2>
Once it's running, Mr. Duck will appear at the bottom right of your screen. 

<p align = "center">
    <img src="assets/usage1.png" width="300">
    <br>
    <em>Hi, I'm Mr. Duck!</em>
</p>

By clicking on him with your mouse, a menu will open up that provides three different options. From left to right: Notes, Media, and Clock.

<p align = "center">
    <img src="assets/usage2.png" width="300">
    <br>
    <em>What to do...</em>
</p>

Notes is just a little notepad that you can refer to, handy for fullscreen applications so you don't have to tab back and forth for some text.
<br>
Media is a set of media buttons that can pause, go back, or fast forward.
<br>
Clock is a clock.
